# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 4.0.x (`Mafesoft.Localization*`) | :white_check_mark: |
| < 4.0 (`Mafe.Localization*`) | :x: |

`Mafesoft.Localization.Xamarin` 4.0.x is deprecated: Xamarin.Forms is out of support, so its security
problems may not be fixed. Migrate to `Mafesoft.Localization.Maui`.

## Reporting a Vulnerability

Please **do not open a public issue** for a security problem.

Report it privately with [GitHub private vulnerability reporting](https://github.com/fmazzant/Localization/security/advisories/new)
(**Security** tab → **Report a vulnerability**), describing:

- the affected package and version;
- how to reproduce the problem;
- the impact you expect.

You will receive an answer as soon as possible. When the problem is confirmed, a fixed version is released and
the advisory is published with credit to the reporter, unless you prefer to stay anonymous.

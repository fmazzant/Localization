Resx vocabularies for [Mafesoft.Localization](https://www.nuget.org/packages/Mafesoft.Localization): reuse the
existing `.resx` files of an application with the XAML markup, the runtime culture switch and the missing-key reporting
of Mafesoft.Localization, without converting them.

Target frameworks: .NET 10, .NET 8, .NET Standard 2.0, .NET Framework 4.6.2.

## Quick start

```
dotnet add package Mafesoft.Localization.Resx
```

```c#
using Mafesoft.Localization;
using Mafesoft.Localization.Resx;

// Strings.resx, Strings.it.resx: the ResourceManager of the class generated by the resx designer
await LocalizationManager.InitAsync(new ResxVocabularyServiceProvider(Strings.ResourceManager), new CultureInfo("it-IT"));
string title = LocalizationManager.Translate("Title");
```

* The vocabulary of a culture has its strings and, for the missing keys, those of the parent cultures and of the
  neutral resources: the same values as `ResourceManager.GetString(key, culture)`.
* Only string resources are read. The provider does not save anything: the `.resx` files are compiled into the app.

See the [documentation](https://github.com/fmazzant/Localization#resx-vocabularies).
